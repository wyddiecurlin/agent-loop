# RGBA media tools

- Add a small, typed RGBA HTTP adapter behind the runtime boundary: discover actions/prompts, execute an allowed action, and inspect jobs/artifacts. Keep rendering in RGBA.
- Connect each user's RGBA account through [USER_ENV.md](USER_ENV.md); keep tokens on the trusted host and expose only authorized operations to the agent.
- Persist operation intent and returned job/artifact IDs through [SESSIONS.md](SESSIONS.md). Resume observation after interruption; never blindly repeat a paid generation.
- Return media references to CLI first, then add artifact cards/playback to Mimo and a new browser voice client using the same backend contract.

**Existing code.** RGBA already exposes action schemas, authoring prompts, uploads, execution, and job inspection through its [HTTP client](../../rgba/cli/src/rgba_cli/api.py) and [routes](../../rgba/backend/app/agent/routes.py). Its [CLI execution code](../../rgba/cli/src/rgba_cli/cmds/sdk.py) distinguishes queued jobs from inline batches: `--no-wait` does not make every action asynchronous. Agent-loop's [runtime.py](../agent_loop/runtime.py) mediates filesystem/process operations and strips credentials from command environments; [web.py](../agent_loop/web.py) provides the existing direct HTTP-client pattern. Mimo's [gateway](../../pet-moment/mobile-app/gateway/server.py) filters events, and its [client](../../pet-moment/mobile-app/Mimo/Agent/AgentClient.swift) has no media artifact contract.

**Smallest implementation.** Follow the existing HTTP schemas directly; do not import RGBA's backend SDK or Claude orchestrator. Use RGBA device authorization with host-managed refresh and its user bearer tokens; [operator secrets bypass user scoping](../../rgba/backend/app/agent/sdk_auth.py) and are unsuitable for shared sessions. Bind account/resource access to the authenticated session. Start with catalog/query/upload and one generation flow, then expand the action allowlist. Record the user's requested output and spending authorization before submission.

**Execution and recovery.** Store an operation ID and request summary before calling RGBA. Persist a returned `job_id` immediately; poll with bounded backoff. Inline actions need bounded execution outside the voice turn. [JOBS.md](JOBS.md) provides the eventual local scheduler/queue; RGBA retains its own remote render workers. If a response is lost, reconcile existing jobs/generations; pause for resolution when ambiguous. A local operation ID alone is not remote idempotency. Job retry/deletion can invalidate caches and must not be automatic recovery.

**Clients and acceptance.** Persist stable artifact IDs/type/title and resolve authorized playback URLs when needed. Add an allowlisted artifact event through both Mimo text and voice paths plus a media viewer; the future browser voice UI reuses it. CLI prints status and links without either display. Verify ownership denial, credential isolation, inline/queued handling, reconnect playback, and lost-response recovery without a second paid render.
