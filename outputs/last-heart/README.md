# LAST HEART

60-second vertical adult science-fiction short.

[Open RGBA production](https://rgba.ai/projects/02242dc4-8c23-491e-9d30-e8d425ca72fa/videos/71fb87eb-2a4a-4278-981a-f17a6e1ff541)

A salvage robot saves a dying mechanical sparrow with its last charge. The bird returns with its flock and restores the robot.

Format: 9:16. Twelve five-second shots. No dialogue. Native generated sound. Reference-only environment master is excluded from the final edit.

Visual continuity: chipped ivory robot, copper sparrow, amber power cores, charcoal machine cathedral. Cinema Studio 3.0 at 1080p and Nano Banana Pro 2K reference frames.
